# 4-bit ALU Verilog

## Project Overview

This project implements a 4-bit Arithmetic Logic Unit (ALU) using Verilog HDL. The ALU is a digital combinational circuit designed to perform arithmetic and logical operations on two 4-bit binary inputs.

The design accepts two 4-bit operands and control signals to select the required operation. The output is generated based on the selected operation and is verified through functional simulation using a Verilog testbench.

The project demonstrates fundamental concepts of digital logic design, Verilog HDL, combinational circuits, and simulation-based verification.
## Features

- 4-bit input operands
- Arithmetic operations
- Logical operations
- Verilog HDL implementation
- Testbench-based verification
- Simulation and waveform analysis
- Combinational logic design

## Supported Operations

The ALU supports the following operations:

| Operation | Function |
|-----------|----------|
| ADD | A + B |
| SUB | A - B |
| AND | A & B |
| OR | A \| B |
| XOR | A ^ B |

## How to Run

1. Clone or download the repository.
2. Open the Verilog source file `alu.v`.
3. Open the testbench file `alu_tb.v`.
4. Compile and simulate the design using a Verilog simulator.
5. Observe the generated waveform to verify the ALU operations.
